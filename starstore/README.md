# THE STAR STORE — Skylar's sky workshop for STARSPELL

One file: `index.html`. No server, no build, nothing fetched. Open it from this page
(https://drbango.com/starstore/), or download the file and open it from your disk — it works
the same. Saves live in the browser you use; EXPORT JSON moves work between a Mac and an iPad.

- **THE SKY SHELF** (the front screen): finished pieces made in the store — Skylar's figures upgraded,
  the worlds, systems and deep sky, events, the menu sky, the zodiac. Tap OPEN ON THE DESK on any card.
- **THE DESK**: tap the sky = a star · tap a star = select (magnitude, colour, NAME IT, EYE) · drop a
  star on a star = a line · the PARTS tray drops a nebula, planet, orbit network, comet… · PLAY shows it
  the way the game draws it.
- **EXPORT**: JSON · PNG card · GAME BLOCK · JUMPR CARD. The badge says PLAIN (the game can draw it
  today) or NEW SKY PIECES (the game learns them in one build first). COPY or DOWNLOAD the jumpr card
  and add it to the Jumper queue, or send it to Wyatt.
