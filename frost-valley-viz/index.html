Architecture

Engine

File Structure

Single monolithic index.html (13,000+ lines). All game logic, UI, CSS, and card data in one file. Pre-commit hook validates JS syntax.

Ability Queue

Abilities fire via queueAbility() — sequential callout system with animations. Recovery net catches dropped state. Callouts drain with configurable speed slider (1x–100x).

Versioning

3 strings must sync on every push: TESTROOM_VERSION, LOCAL_V (line ~11), cache-version.txt. Browser auto-reloads on mismatch. Drift causes reload loops.

Firebase

Project testroom-75200. Realtime DB stores persistent standings (wins/losses per ghost). Wilson Score lower bound (WSR, z=1.96) for rankings — rewards game volume.

Duel Phase

Shipped v390. Previous round loser commits resources first; rolls stay simultaneous. Round 1: lower maxHP goes first. Creates sacrifice play (lose R1 on purpose for R2 initiative).

Spiritkin Chat

Click any gallery ghost to talk to it in character — Gary AI in disguise. Cloudflare Worker proxy at gary-chat-proxy.drbango.workers.dev. Doubles as art direction tool.

Design Rules

Feedback Memory

No Carryover Tracking

No counters, tokens, or multi-turn tracking. Everything resolves within the round. Designed for kids and dads.

Healing Cap: 2 HP/Turn

Healing >2 HP/turn breaks the game. Keep healers rare. The game is about risk and aggression, not stalling.

Healing Overclocks Past Max

ALL healing overclocks past maxHP (hp += N, no cap). Only exceptions: Healing Seed resource use and Biscuit. Never write Math.min(maxHp, hp+N).

Interactive Dice Reveals

Player-rollable abilities need click-to-roll modals, never auto-resolve. The reveal IS the gameplay. Examples: Sylvia, Balatron.

Cornelius Check

Every new pre-roll sideline ability MUST check for Cornelius (45) Antidote. Add !hasSideline(enemy, 45) + ANTIDOTE callout.

Steal = Transfer

Steal abilities must TRANSFER dice to the thief, not just subtract from enemy. "Steal" = transfer; "strip" = subtract only.

Use Existing Systems

Always use existing resource systems (burn picker, LS window, MS picker) instead of reimplementing inline.

Mechanic Collapse

When a proposed mechanic needs cross-round state, compress it onto a single card's same-round ability. Drop the tracking layer.

Version Bump

ALWAYS bump TESTROOM_VERSION + LOCAL_V + cache-version.txt in the same commit. 3 strings must sync or reload loops.

Audit Whole Family

When one instance of a shared pattern breaks, audit the whole family of similar abilities — don't patch the symptom.

Key Findings

HP is king — the single strongest stat. +1 damage is massive (33–100% increase depending on base). Defense/healing dominates the meta. Sideline support is critical to team composition.

Design Principle

Simple cards can be elite. Complexity ≠ power. The sim confirmed that straightforward stat advantages (HP, dice count, raw damage) outperform intricate conditional mechanics.
