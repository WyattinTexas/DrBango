## BUGS FOUND

### CRITICAL
1. **Market seller coins NOT credited** — Buyer's coins are deducted and item transferred, but seller never receives payment. The coins vanish. Comment in code acknowledges this at line ~6067. Needs Firebase transaction to credit seller's /players/{uid}/coins.

### MEDIUM
2. **No chat rate limiting** — players can spam unlimited messages with no throttle
3. **Arena simulation incomplete** — challenges post to Firebase as 'pending' but auto-resolution logic may not fully execute
4. **Anonymous auth only** — UIDs are ephemeral, no persistent identity across devices

### LOW
5. **Guild disband has no confirmation** — one click destroys the guild
6. **Tip lookup by name only** — could have edge cases with duplicate names

## UX FRICTION
1. Market is location-gated (near hub buildings) — can't check market from the field
2. Arena only shows players with hubY < 15 — excludes players in other regions
3. No notification when someone buys your market listing
4. Guild invite requires being in inspect modal — no quick-invite from chat

## WHAT FELT GOOD
1. Cantina as a separate social space with its own chat — SWG energy
2. Guild tags showing on all chat messages and player names
3. Tipping with atomic Firebase transactions — secure and real
4. Player inspect showing full profile (team, gear, mastery, titles)
5. 3-listing market cap prevents spam while allowing meaningful trade
6. Presence updates every 500ms — smooth other-player movement

## RECOMMENDATIONS
1. **FIX MARKET SELLER PAYMENT** — use Firebase transaction to credit seller coins when buyer purchases
2. Add chat rate limiting (1 msg per second)
3. Add purchase notification for sellers
4. Allow market browsing from anywhere (remove location gate for browsing, keep it for selling)
5. Add Firebase security rules file
6. Add guild disband confirmation modal
