How It Works

Each die is a CSS cube with 6 faces using perspective + transform-style: preserve-3d. No WebGL, no canvas — pure DOM elements with CSS 3D transforms animated via requestAnimationFrame.

Every throw randomly selects one of 6 choreographed throw profiles, each with its own personality:

The Bloom

Steep arc, dice unfurl like petals

The Bank Shot

All dice hit the top wall first

The Cross-Table

Full send diagonal to the far wall

The Spiral

Widest orbit to tightest drop

The Scatter

Each die at a wildly different angle

The Gentle Toss

Short lob, barely leaves the hand

Physics includes wall bouncing with decaying coefficients, dice-to-dice repulsion, speed-dependent friction (fast = ice, slow = felt), and rotation homing that magnetically settles dice flat.
