## BUGS FOUND

### MEDIUM
1. **Schematic unlock reward never applied** — ef_003 quest has `schematicUnlock: true` but completeQuest() doesn't handle it. Dead reward.
2. **Day rollover mid-quest** — old quest ID has yesterday's daySeed but can still be completed today. May cause confusion but not game-breaking.
3. **battleFledThisSession unused** — quest type `win_no_flee` exists but the flee flag isn't checked in checkQuestProgress(). Players can flee and still get credit.

### LOW
4. **Offline completion gap** — quest progress only persists on explicit saveGame() calls, not on each progress increment.
