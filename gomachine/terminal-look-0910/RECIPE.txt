TERMINAL LOOK 0910 — the COMPUTER look
=======================================
Published 2026-09-11 from the big Mac for the Go Machine.
Live: https://drbango.com/gomachine/terminal-look-0910/   (unlisted path; nothing private in here)

WHAT IT LOOKS LIKE
------------------
Before 9/10 every Terminal window was the stock "Basic" profile: black text on white, the small
11-point stock font, and a title bar stuffed with the running command, its arguments, the tty and
the window size ("caffeinate < claude --session-id ... --goal ...").  Since 9/10 every window uses
a profile called COMPUTER: warm near-white text on an opaque dark-navy background, amber only for
bold text and the block cursor, Atkinson Hyperlegible Mono at 14 point with the letters spaced a
touch wider and the lines a touch taller, nothing blinks, nothing beeps (the screen flashes
instead), 112 columns by 34 rows, and the window title and tab show ONLY what the app inside sets
(Claude Code's "* Navigator") — Terminal adds nothing.  macOS Dark Mode is on so the window header
is dark too.  Three sister profiles (Computer Green, Computer Red, Computer Day) switch with
`computer green|red|day`; `computer on|off` toggles the whole look; bare `computer` plays a boot
screen, then starts claude.

Wyatt's rulings that shaped it (9/10): "a lot easier to read, a little less abrasive" -> "This is
the text of our life; it needs to be even easier to read. Comprehension distraction at a minimum"
-> "the most readable font in the world, data proven" -> headers "look so confusing... can't they
just be simple?"

APPLY IT (Go Machine: macOS 26, zsh, Terminal.app)
--------------------------------------------------
  mkdir -p ~/terminal-look-0910 && cd ~/terminal-look-0910
  B=https://drbango.com/gomachine/terminal-look-0910
  for f in $(curl -sf $B/FILES.txt); do mkdir -p "$(dirname "$f")"; curl -sf -o "$f" "$B/$f" || echo "FAILED $f"; done
  bash apply-terminal-look.sh --dry-run      # prints the plan, writes nothing
  bash apply-terminal-look.sh                # applies; then Cmd+Q Terminal and open it again
  Then Dark Mode: System Settings > Appearance > Dark  (or `computer on` once, in a new shell;
  macOS asks once to let Terminal control System Events — the script itself never asks anything).
  Re-running the script is safe: it reports "already installed" and changes nothing.

The kit   ->  ~/computer/
  computer.zsh       the `computer` function: on | off | green | red | day | status | (bare) boot + claude
  look.sh            applies a profile to every open tab + default + startup and flips Dark Mode
                     (AppleScript to Terminal + System Events: macOS asks ONCE to allow it)
  boot.sh            the boot screen (256-colour, block logo painted with background cells, seam-free)
  make-profiles.py   regenerates the four .terminal files (colours + font archived through JXA)
  install.sh         regen + re-import; deletes the old Computer* sets first because Terminal never
                     replaces a same-named profile on import — it silently appends " 1"
  Computer*.terminal  the four profiles   README.md   OFL-AtkinsonHyperlegibleMono.txt

Claude Code   ->  every ~/.claude*/settings.json

WHAT THE SCRIPT CANNOT DO, AND WHY
----------------------------------
  - Flip Dark Mode: needs AppleScript into System Events, which macOS gates behind a one-time
    Allow click. The script reports it; `computer on` or System Settings does it.
  - Restyle windows that are already open: a profile applies to new windows; open ones change only
    through AppleScript (`computer on`) or a reopen.
  - Replace an existing same-named profile through Terminal's importer (it appends " 1"): if a
    profile exists but differs, the script writes the entry straight into the defaults domain and
    asks for a relaunch.
  - Colour the window header or tab bar: macOS chrome. Dark Mode is the only lever.
  - Guarantee the look inside a window opened by another launcher that sets its own colours (jumpr
    on the big Mac does): that launcher's tint wins over the profile background, by design.
