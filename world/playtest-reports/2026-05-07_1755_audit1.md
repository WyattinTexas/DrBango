## Bug Found & Fixed
**InvalidOperationException: Input.GetKey() vs Input System**
- Cause: Project uses `activeInputHandler: 1` (new Input System only) but WASD code uses `Input.GetKey()` (old API)
- Fix: Changed `activeInputHandler` to `2` (both systems) in ProjectSettings.asset
- Impact: CRITICAL — prevented all WASD movement and spammed red errors in console
